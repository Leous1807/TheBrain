# Description
Security analysts are responsible for **monitoring** and **protecting** **information** and **devices**. They are also most of the times **the first to respond** to security incident.
Security analysts also help in **security exercises** such as **finding weaknesses in security measures**. They may also help software developers in developing **prevention software**.

### Responsibilities
- Protecting computers and systems
- Installing prevention softwares
- Periodic security audits and reviews
