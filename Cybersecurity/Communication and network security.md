## Overview
Communication and Network Security is the CISSP domain focused on designing, managing, and securing physical network architectures, wireless communication channels, and data transport layers.

## Key Mechanics
* **Network Infrastructure:** Securing hardware routing, switching, and boundary systems like a [[Firewall]].
* **Transmission Security:** Protecting data in transit via network encryption protocols (e.g., TLS, IPsec) and network segmentation.
