# Description
In 1989 this program was developed to assess the size of the internet. The program would crawl the web and install itself on any computer it stumbled upon. The program failed to keep track of the computers it had already compromised and kept installing itself over and over on the same device causing it to run out of memory and crash. This attack directly led to creation of computer emergency response teams (CERTS). CERTS still exist today but their roles has expanded to include more responsibilities.
