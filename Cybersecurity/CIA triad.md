# Description
CIA triad is a **foundational model** the helps how organizations inform risk when setting up **systems** and **security policies**

### CIA
- Confidentiality: Only authorized users can access specific data and assets.
- Integrity: Data is correct, authentic and reliable.
- Availability: Data is accessible to those who are authorized to access it.
