## Overview
A computer virus is a type of malicious software designed to insert its own code into legitimate programs or files. It requires human interaction or execution to spread and alter system operations.

## Key Mechanics
* **Host Requirement:** Unlike worms, a virus cannot spread independently; it requires a host file or execution by an end-user.
* **Payload Execution:** Modifies system parameters, corrupts files, disrupts hardware processes, or steals system information upon activation.

## Security Impact & Context
* **Threat/Risk:** File corruption, system instability, unauthorized code execution, and data destruction.
* **Mitigation/Defense:** Antivirus/EDR software, patch management, restricted execution permissions, and user security awareness training.
