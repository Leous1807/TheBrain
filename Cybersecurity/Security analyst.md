## Overview
Security analysts are front-line security professionals responsible for monitoring, defending, and maintaining the security of an organization's systems, networks, and data assets.

## Key Responsibilities
* **Incident Response:** Frequently serves as the first responder during a detected security incident or anomaly.
* **System Defense:** Installs, configures, and maintains security applications and endpoint protection tools.
* **Security Audits:** Performs periodic security reviews, audits, and assessments to identify system vulnerabilities.
* **Collaborative Defense:** Partners with developers to establish guidelines for secure application development and threat prevention.
