## Overview
A firewall is a network security device or software that monitors, filters, and controls incoming and outgoing network traffic based on an organization's predetermined security rules.

## Key Mechanics / How It Works
* **Traffic Inspection:** Evaluates packets against defined Access Control Lists (ACLs).
* **Filtering Criteria:** Decisions are made based on source/destination IP addresses, protocols, or port numbers.
* **Types:** Ranges from stateless packet filters to stateful inspection firewalls and Next-Generation Firewalls (NGFWs).

## Security Impact & Context
* **Threat/Risk:** Prevents unauthorized external access and deters internal lateral movement by malicious actors.
* **Mitigation/Defense:** Serves as a primary perimeter defense mechanism within [[Communication and network security.
