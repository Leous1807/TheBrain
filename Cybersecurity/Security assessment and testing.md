## Overview
Security Assessment and Testing is the CISSP domain focused on evaluating the effectiveness of security controls, analyzing security data, and conducting systematic audits to monitor risks and vulnerabilities.

## Key Mechanics
* **Control Testing:** Validating that administrative, technical, and physical security controls perform as expected.
* **Vulnerability Monitoring:** Collecting and analyzing security log data to spot weaknesses and active threats.
* **Auditing:** Executing formal audits to verify regulatory compliance and security posture.
