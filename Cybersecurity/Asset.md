## Overview
An asset is any item, data point, system, device, or personnel that holds tangible or intangible value for an organization.

## Categories & Context
* **Digital Assets:** Database records, [[PII]], intellectual property, software source code.
* **Physical Assets:** Servers, network hardware (e.g., [[Firewall]]), laptops, facilities, physical documentation.
